# Requirements Reference (from SFT-WEB-2026-042-SRS-v1.2)

## Must-have (MVP — get these solid first)
- FR-01 Registration, login, personalised dashboard
- FR-02 Interactive learning modules
- FR-03 Quizzes per module
- FR-04 Progressive levels with points and rewards
- FR-05 Persist scores, badges, level status
- FR-07 Knowledge hub (articles, FAQs, case examples)
- FR-11 Child-friendly, responsive interface

## Should-have (after MVP works)
- FR-06 Revisit completed topics
- FR-08 Curated law/rights info via APIs
- FR-09 Feedback/comments on modules
- FR-10 Multi-language support

## Mid-point review target
Must be demonstrable: **FR-01, FR-02, FR-03, FR-05**
Deliver: repo link, 3–5 min demo video, status note.

## Acceptance criteria to keep visible while building
- AC-01 → FR-01: register → login → dashboard shown
- AC-02 → FR-03: complete quiz → score calculated and shown
- AC-03 → FR-05: return to dashboard → updated score/badges/level shown
- AC-04 → FR-04: points threshold reached → level unlocked, reward recorded
- AC-05 → FR-06: reopen completed topic → progress not lost
- AC-06 → FR-07: open knowledge hub → articles/FAQs/case examples listed
